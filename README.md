## 🚀 Featured work

### 🧬 AMR Intelligence Platform · *final-year project, team of three* · [repo](https://github.com/hhammza/FYP1)
Predicts whether a bacterium resists an antibiotic, from its lab profile or its complete genome. I own the **platform**: the Django REST API, the Flask web app, and everything between the models and the user.

- **Models it serves:** a LightGBM forecaster trained on **6.3 M** BV-BRC resistance records, and a genome model with **AUC 0.935 on lab-tested genomes it never saw**
- **API hardening:** secrets from the environment, admin-token endpoints, per-IP rate limits, upload limits, and clear 400s for bad input instead of server errors
- **Features:** batch CSV prediction (10,000 rows), CSV / PDF / PNG exports, a resistance-genes panel, a genome-models report, and a site that works fully offline
- **Engineering:** **120+ automated tests** run by GitHub Actions on every push, a Docker image with NCBI AMRFinderPlus pinned to the model's training database (checked in CI on a genome the model never saw), and model metrics that drive every number on the site

`Python` `Django REST` `Flask` `LightGBM` `pandas` `Plotly` `Docker` `ReportLab`
